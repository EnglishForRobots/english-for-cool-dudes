B — True or False?
Circle T (True) or F (False).
StatementT  /  F
1. A shareholder activity can be freely charged to subsidiaries simply because the parent decided to do it.
2. Centralised cybersecurity monitoring that clearly reduces local risk can pass the benefit test.
3. A good allocation key should reflect how the cost actually relates to the benefit received.
4. Duplicate services always pass the benefit test, as long as HQ documents them properly.
5. Low value-adding intra-group services can sometimes use a simplified pricing approach.
6. The arm's length mark-up concept only matters for goods, never for services.
